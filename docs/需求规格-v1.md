# 二胡练习工具 · 需求规格 v1.0

> 浏览器端静态单页应用。零后端、零网络请求、零第三方库。
> 本文档是三轮需求确认的结果，任何改动请先更新决策表 D-01 ~ D-16。

---

## 1. 产品定位

帮助二胡学习者（兼顾其他乐器）在浏览器里完成四件事：

| 目标 | 对应模块 | 一句话价值 |
|---|---|---|
| 练节奏 | 节拍器 | 拍子稳不稳，机器说了算 |
| 练音准 | 调音器 + 跟奏音准反馈 | 二胡没有品位，音准全靠耳朵，这里给耳朵一个标尺 |
| 练耳朵 | 听音训练 | 音程、和弦、旋律听写 |
| 跟谱练习 | 乐谱跟练 | 简谱 + 指法弓法，变速循环跟练 |

**不做**：账号系统、云同步、社交、付费、多轨录音混音、图片谱 OCR、服务端文件上传、乐谱导入（一期）。

## 2. 决策表

| 编号 | 决策项 | 结论 | 带来的影响 |
|---|---|---|---|
| D-01 | 乐谱来源 | 一期仅内置练习谱，不做导入 | 不需要 OSMD / abcjs / VexFlow，谱面数据用内部 JSON schema |
| D-02 | 交付形态 | 多文件 + 库 vendor 到本地 | 内网、离线、断网都能跑 |
| D-03 | 麦克风 | 启用 + 自动降级 | 非 HTTPS 或权限被拒时，自动隐藏麦克风相关 UI，其余功能照常 |
| D-04 | 音源 | Web Audio 合成音 | 零体积、零依赖 |
| D-05 | 谱面呈现 | 简谱数字 + 音名，DOM/CSS 渲染 | 零依赖，可做当前音符高亮与自动滚动 |
| D-06 | 标注深度 | 指法常显 + 弓法可开关 | 两套数据都要录，默认只显示指法 |
| D-07 | 曲库范围 | 入门 4 首 + 基本功 + 每日基本功专项 | 一期约 12 条 |
| D-08 | 跟练控制 | 变速不变调 + A-B 循环 + 预备拍/节拍器叠加 + 当前音高亮 | 四项全做 |
| D-09 | 听音题型 | 音程听辨、和弦性质听辨、旋律听写填空 | 以选择题为主 |
| D-10 | 音准反馈 | 简化版：实时音分偏差指针，不评分 | 依赖麦克风，可降级 |
| D-11 | 调音器 | 通用十二平均律 + 常用调/常用乐器定弦预设，**不写死二胡** | 换乐器照样能用 |
| D-12 | 练习记录 | 只存设置，不做统计 | IndexedDB 仅一个键值 store |
| D-13 | 记号体系 | 标准民乐符号 | 拉弓 ▬、推弓 ▭、连弓 ⌒、指法 一二三四 |
| D-14 | 标注分级 | 入门 4 首全标指法 + 弓法；基本功只标指法 | 控制录入工作量（本项目最大成本项） |
| D-15 | 视觉风格 | 深色工业风为主，设置中可切浅色 | 主色 #0F172A / #1E293B，单一强调色 |
| D-16 | 第三方库 | 一期 **零第三方库** | vendor/ 目录一期为空，后续按需填充 |

### 2.1 关于 D-02 与 D-16 的结论

因为选了「内置谱 + 简谱 DOM + 合成音」，一期**不需要任何第三方库**。所以「vendor 到本地」的策略保留为目录约定，实际 vendor/ 为空。这是一件好事：没有 CDN 依赖、没有版本冲突、没有体积负担。

### 2.2 开发期修订（2026-09-23）

| 编号 | 修订 | 原因 |
|---|---|---|
| D-07-R1 | 曲库一期最小集：小星星、欢乐颂 + 7 条基本功（用户拍板「曲目先这么多，优先实现功能，后续增量补」） | 功能优先 |
| D-07-R2 | 八月桂花遍地开暂缓：多来源音高出入大、二胡独奏版超一把位；茉莉花已查证（三个独立来源音高一致，1=D 全落一把位）待录 | 谱面正确性优先于曲目数量 |
| D-14-R1 | 指法与弓法采用「自动生成 + 显式覆盖」：指法按调查表自动填充（内弦 D4 起四音、外弦 A4 起五音，沿调音阶取音），弓法自动交替、`[连]` 组内同弓；数据中仅需写显式标记 | 消除逐音标注成本（本项目最大成本项），且按调保证正确（G 调外弦二指=C5 而非 C#5） |
| K-07 | index.html 全部脚本加 `defer`；boot 增加核心缺失 fail-fast 守卫 | 消除脚本执行顺序隐患 |

## 3. 功能规格

### 3.1 节拍器

| 编号 | 功能 | 规格 |
|---|---|---|
| M-01 | BPM | 30–300，滑杆 + 数字输入 + Tap tempo（连敲 4 次取平均） |
| M-02 | 拍号 | 2/4、3/4、4/4、6/8 |
| M-03 | 细分 | 整拍 / 八分 / 十六分 / 三连音 |
| M-04 | 重音 | 首拍重音；可扩展为「每小节第 N 拍重音」 |
| M-05 | 音色 | 木鱼（噪声 + 带通）、正弦短音、高频点击，三档可切 |
| M-06 | 可视化 | 拍点圆点跳动 + 钟摆摆动 |
| M-07 | 渐快训练 | 每 N 小节 +X BPM，到 M BPM 停止或循环 |
| M-08 | 静音小节 | 随机静音 N 小节，考验内心拍感 |
| M-09 | 音量 | 音量滑杆 + 静音 |
| M-10 | 精度 | 前瞻调度：25ms 轮询 + 100ms 排程窗口，按 `audioContext.currentTime` 排音，**禁用 setInterval 直接发声** |

### 3.2 调音器

| 编号 | 功能 | 规格 |
|---|---|---|
| T-01 | 基准音 | A4 = 440 Hz，可调 430–450 Hz |
| T-02 | 检测范围 | 60–1200 Hz，覆盖二胡全音域 |
| T-03 | 检测算法 | 时域自相关（AMDF）+ 抛物线插值，目标精度 ±3 音分 |
| T-04 | 显示 | 音名 + 偏差音分指针（−50 ~ +50）+ 实际频率 Hz + 稳定度指示 |
| T-05 | 定弦预设 | 可编辑的预设库（见 3.2.1） |
| T-06 | 参考音 | 点击预设音名播放长音，用于对照校音 |
| T-07 | 降级 | 无麦克风 → 隐藏检测区，仅保留参考音（D-03） |

#### 3.2.1 定弦预设库

二胡标准定弦为内弦 d1、外弦 a1（D4–A4，纯五度），换调不换弦高，只换弦式：

| 调 | 弦式 | 内弦唱名 | 外弦唱名 | 定弦音高 |
|---|---|---|---|---|
| D 调 | 1-5 弦（do-sol） | do | sol | D4 – A4 |
| G 调 | 5-2 弦（sol-re） | sol | re | D4 – A4 |
| F 调 | 6-3 弦（la-mi） | la | mi | D4 – A4 |
| C 调 | 2-6 弦（re-la） | re | la | D4 – A4 |
| A 调 | 4-1 弦（fa-do） | fa | do | D4 – A4 |
| bB 调 | 3-7 弦（mi-si） | mi | si | D4 – A4 |
| 二泉映月用弦（1=G，低五度） | 5-2 弦 | sol | re | G3 – D4 |

通用乐器预设（不写死二胡，D-11）：小提琴 G3-D4-A4-E5、吉他 E2-A2-D3-G3-B3-E4、尤克里里 G4-C4-E4-A4、大提琴 C2-G2-D3-A3。

### 3.3 听音训练

| 编号 | 题型 | 规格 |
|---|---|---|
| E-01 | 音程听辨 | 播放两音（旋律/和声两种呈现），从 8–12 个音程中选；难度分级：先自然音程，后变化音程 |
| E-02 | 和弦性质听辨 | 判断大 / 小 / 减 / 增；进阶可加大七、属七 |
| E-03 | 旋律听写填空 | 播放 4–8 音短句，给出简谱骨架，隐藏 2–3 个音，用音名按钮填 |
| E-04 | 交互 | 播放 / 重播、答题、即时反馈（对错 + 重播正确答案做对比） |
| E-05 | 组卷 | 连续 N 题一组，组末显示本组正确率 |

**统计边界（D-12）**：正确率只在**当前会话内**显示，页面刷新即清空，不写入 IndexedDB。

## 4. 数据结构

### 4.1 谱面 JSON schema

```json
{
  "id": "xiaoxingxing",
  "title": "小星星",
  "category": "basic",
  "key": "D",
  "stringMode": "1-5",
  "tuning": ["D4", "A4"],
  "bpm": 88,
  "meter": "4/4",
  "sections": [{ "name": "A", "fromBar": 1, "toBar": 8 }],
  "notes": [
    {
      "d": "1",
      "oct": 0,
      "p": "D4",
      "dur": 1,
      "f": "一",
      "b": "▬",
      "s": "内",
      "tie": false,
      "slide": null
    }
  ]
}
```

| 字段 | 含义 | 取值 |
|---|---|---|
| `d` | 简谱数字 | `"0"`–`"7"`，0 为休止 |
| `oct` | 八度点 | `-1` 低音点、`0` 中音、`+1` 高音点 |
| `p` | 科学音名 | 用于发声与音准比对 |
| `dur` | 时值 | 单位 = 拍（1 = 四分音符，0.5 = 八分音符） |
| `f` | 指法 | `空` / `一` / `二` / `三` / `四` |
| `b` | 弓法 | `▬` 拉弓、`▭` 推弓、`⌒` 连弓 |
| `s` | 弦别 | `内` / `外` |
| `tie` | 延音线 | 布尔 |
| `slide` | 滑音 | `null` 或 `{ "to": "A4", "type": "up" }` |

小节线由 `meter` 与 `dur` 累计推导，不单独存。

### 4.2 存储

IndexedDB 单库 `erhu-trainer`，单 store `settings`，键值结构 `{ key, value }`。只存：主题、基准音高、默认 BPM、音色选择、音量、弓法显示开关、最近使用的曲目。

## 5. 技术架构

### 5.1 目录结构

```
index.html
css/
  base.css            变量、重置、排版
  layout.css          顶部导航 + 面板容器
  metronome.css
  tuner.css
  ear.css
  score.css
js/
  app.js              Tab 路由、模块初始化
  core/audio.js       AudioContext 单例 + 前瞻调度器
  core/synth.js       合成音色
  core/pitch.js       音高检测（自相关）
  core/notation.js    音名 / 频率 / 音分换算
  core/store.js       IndexedDB 设置持久化
  modules/metronome.js
  modules/tuner.js
  modules/ear.js
  modules/score.js
  data/scores.js      内置曲库
  data/exercises.js   基本功练习
  data/tunings.js     定弦预设
vendor/               一期为空（D-16）
sw.js                 离线缓存
```

### 5.2 关键技术点

| 编号 | 要点 | 做法 |
|---|---|---|
| K-01 | 节奏精度 | 前瞻调度器：25ms 轮询，`currentTime + 0.1s` 窗口内排音 |
| K-02 | 音高检测 | AnalyserNode 时域数据 + 自相关 + 抛物线插值，2048 点窗 |
| K-03 | 降级判定 | `!window.isSecureContext` 或 `!navigator.mediaDevices?.getUserMedia` → 隐藏麦克风 UI |
| K-04 | 变速不变调 | 只缩放 `dur` 与调度间隔，不改 `p` 的频率 |
| K-05 | 离线 | Service Worker 预缓存全部静态资源 |
| K-06 | 打开方式 | **推荐** `python -m http.server` 等本地静态服务器；`file://` 下节拍器 / 听音 / 跟练全部可用，但麦克风与 Service Worker 自动失效（符合 D-03 降级设计） |

### 5.3 界面

顶部 5 个 Tab：节拍器 / 调音器 / 听音训练 / 乐谱跟练 / 设置。深色工业风（#0F172A / #1E293B + 单一强调色），设置中可切浅色。响应式，桌面为主，兼容 ≥360px 宽度。

键盘快捷键：空格 = 播放/停止，`←` `→` = 调速，`[` `]` = 设 A/B 点。

## 6. 验收标准

| 编号 | 场景 | 预期 |
|---|---|---|
| A-01 | 节拍器 120 BPM / 4/4 连续运行 5 分钟 | 累计漂移 < 50ms |
