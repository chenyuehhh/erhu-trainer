浏览器端静态单页应用。零后端、零网络请求、零第三方库。本文档是三轮需求确认的结果，任何改动请先更新决策表 D-01 ~ D-16。

1. 产品定位

帮助二胡学习者（兼顾其他乐器）在浏览器里完成四件事：

目标 对应模块 一句话价值
练节奏节拍器拍子稳不稳，机器说了算
练音准调音器 + 跟奏音准反馈二胡没有品位，音准全靠耳朵，这里给耳朵一个标尺
练耳朵听音训练音程、和弦、旋律听写
跟谱练习乐谱跟练简谱 + 指法弓法，变速循环跟练

不做：账号系统、云同步、社交、付费、多轨录音混音、图片谱 OCR、服务端文件上传、乐谱导入（一期）。

2.1 关于 D-02 与 D-16 的结论

因为选了「内置谱 + 简谱 DOM + 合成音」，一期不需要任何第三方库。所以「vendor 到本地」的策略保留为目录约定，实际 vendor/ 为空。这是一件好事：没有 CDN 依赖、没有版本冲突、没有体积负担。

3. 功能规格

3.1 节拍器

编号 功能 规格
M-01BPM30–300，滑杆 + 数字输入 + Tap tempo（连敲 4 次取平均）
M-02拍号2/4、3/4、4/4、6/8
M-03细分整拍 / 八分 / 十六分 / 三连音
M-04重音首拍重音；可扩展为「每小节第 N 拍重音」
M-05音色木鱼（噪声 + 带通）、正弦短音、高频点击，三档可切
M-06可视化拍点圆点跳动 + 钟摆摆动
M-07渐快训练每 N 小节 +X BPM，到 M BPM 停止或循环
M-08静音小节随机静音 N 小节，考验内心拍感
M-09音量音量滑杆 + 静音
M-10精度前瞻调度：25ms 轮询 + 100ms 排程窗口，按 audioContext.currentTime 排音，禁用 setInterval 直接发声

3.2 调音器

编号 功能 规格
T-01基准音A4 = 440 Hz，可调 430–450 Hz
T-02检测范围60–1200 Hz，覆盖二胡全音域
T-03检测算法时域自相关（AMDF）+ 抛物线插值，目标精度 ±3 音分
T-04显示音名 + 偏差音分指针（−50 ~ +50）+ 实际频率 Hz + 稳定度指示
T-05定弦预设可编辑的预设库（见 3.2.1）
T-06参考音点击预设音名播放长音，用于对照校音
T-07降级无麦克风 → 隐藏检测区，仅保留参考音（D-03）

3.2.1 定弦预设库

二胡标准定弦为内弦 d1、外弦 a1（D4–A4，纯五度），换调不换弦高，只换弦式：

调 弦式 内弦唱名 外弦唱名 定弦音高
D 调1-5 弦（do-sol）dosolD4 – A4
G 调5-2 弦（sol-re）solreD4 – A4
F 调6-3 弦（la-mi）lamiD4 – A4
C 调2-6 弦（re-la）relaD4 – A4
A 调4-1 弦（fa-do）fadoD4 – A4
bB 调3-7 弦（mi-si）misiD4 – A4
二泉映月用弦（1=G，低五度）5-2 弦solreG3 – D4

通用乐器预设（不写死二胡，D-11）：小提琴 G3-D4-A4-E5、吉他 E2-A2-D3-G3-B3-E4、尤克里里 G4-C4-E4-A4、大提琴 C2-G2-D3-A3。

3.3 听音训练

编号 题型 规格
E-01音程听辨播放两音（旋律/和声两种呈现），从 8–12 个音程中选；难度分级：先自然音程，后变化音程
E-02和弦性质听辨判断大 / 小 / 减 / 增；进阶可加大七、属七
E-03旋律听写填空播放 4–8 音短句，给出简谱骨架，隐藏 2–3 个音，用音名按钮填
E-04交互播放 / 重播、答题、即时反馈（对错 + 重播正确答案做对比）
E-05组卷连续 N 题一组，组末显示本组正确率

统计边界（D-12）：正确率只在当前会话内显示，页面刷新即清空，不写入 IndexedDB。

3.4 乐谱跟练

编号 功能 规格

S-02分行按拍号自动分小节、按容器宽度自动折行
S-03跟随当前音符高亮 + 自动滚动保持光标可见

S-05变速0.5x – 1.5x 无级调速，音高不变
S-06A-B 循环选定小节区间循环，支持拖拽选区与数字输入
S-07预备拍开始前倒数一个小节，可关
S-08节拍器叠加跟练时叠加节拍器打点，音量独立
S-09移调±12 半音（可选，二胡换调用）
S-10音色锯齿波 + 60ms 慢起音 + 5.5Hz 轻颤音（弦乐近似），设置中可切正弦 / 三角 / 锯齿

4. 数据结构

4.1 谱面 JSON schema

{
  "id": "xiaoxingxing",
  "title": "小星星",
  "category": "basic",
  "key": "D",
  "stringMode": "1-5",
  "tuning": ["D4", "A4"],
  "bpm": 88,
  "meter": "4/4",
  "sections": [{ "name": "A", "fromBar": 1, "toBar": 8 }],
  "notes": [
    {
      "d": "1",
      "oct": 0,
      "p": "D4",
      "dur": 1,
      "f": "一",
      "b": "▬",
      "s": "内",
      "tie": false,
      "slide": null
    }
  ]
}
字段 含义 取值
d简谱数字"0"–"7"，0 为休止
oct八度点-1 低音点、0 中音、+1 高音点
p科学音名用于发声与音准比对
dur时值单位 = 拍（1 = 四分音符，0.5 = 八分音符）
f指法空 / 一 / 二 / 三 / 四
b弓法▬ 拉弓、▭ 推弓、⌒ 连弓
s弦别内 / 外
tie延音线布尔
slide滑音null 或 { "to": "A4", "type": "up" }

小节线由 meter 与 dur 累计推导，不单独存。

4.2 存储

IndexedDB 单库 erhu-trainer，单 store settings，键值结构 { key, value }。只存：主题、基准音高、默认 BPM、音色选择、音量、弓法显示开关、最近使用的曲目。

5.2 关键技术点

编号 要点 做法
K-01节奏精度前瞻调度器：25ms 轮询，currentTime + 0.1s 窗口内排音
K-02音高检测AnalyserNode 时域数据 + 自相关 + 抛物线插值，2048 点窗
K-03降级判定!window.isSecureContext 或 !navigator.mediaDevices?.getUserMedia → 隐藏麦克风 UI
K-04变速不变调只缩放 dur 与调度间隔，不改 p 的频率
K-05离线Service Worker 预缓存全部静态资源
K-06打开方式推荐 python -m http.server 等本地静态服务器；file:// 下节拍器 / 听音 / 跟练全部可用，但麦克风与 Service Worker 自动失效（符合 D-03 降级设计）

5.3 界面

顶部 5 个 Tab：节拍器 / 调音器 / 听音训练 / 乐谱跟练 / 设置。深色工业风（#0F172A / #1E293B + 单一强调色），设置中可切浅色。响应式，桌面为主，兼容 ≥360px 宽度。

键盘快捷键：空格 = 播放/停止，← → = 调速，[ ] = 设 A/B 点。

6. 验收标准

编号 场景 预期
A-01节拍器 120 BPM / 4/4 连续运行 5 分钟累计漂移 < 50ms
A-02节拍器切换拍号与细分打点数量与强弱符合拍号
A-03调音器输入 440Hz 标准音源显示 A4，偏差 ±3 音分内
A-04调音器输入 293.66Hz显示 D4（二胡内弦）
A-05禁用麦克风权限后打开麦克风面板隐藏，参考音与其他 Tab 正常
A-06file:// 直接打开节拍器、听音、跟练可用；麦克风与 SW 自动失效并给出提示
A-07跟练变速 0.5x时长翻倍，音高不变
A-08A-B 循环播放到 B 点立即回到 A 点，不中断
A-09指法 / 弓法开关默认只显示指法，开启后叠加弓法符号
A-10断网（离线）打开已缓存时全部功能可用
A-11设置修改后刷新设置项保持
