# 二胡练习台 ErhuTrainer

浏览器端静态音乐练习工具：**节拍器 / 调音器 / 听音训练 / 乐谱跟练**。零后端、零第三方库、零网络请求，数据只存本机。

需求规格见 `../docs/需求规格-v1.md`（决策表 D-01 ~ D-16）。

## 快速开始

```bash
cd erhu-trainer
node tools/serve.mjs
# 浏览器打开 http://127.0.0.1:8931/
```

任何静态服务器都可以（`python -m http.server 8931`、`npx serve` 等）。`tools/serve.mjs` 是自带的零依赖静态服务器，响应带 `Cache-Control: no-store`，本地调试不会被缓存干扰。

**打开方式差异（重要）**：

| 方式 | 节拍器/听音/跟练 | 麦克风功能 | 离线缓存 |
|---|---|---|---|
| localhost / HTTPS | ✅ | ✅ | ✅ |
| file:// 双击打开 | ✅ | ❌ 自动降级隐藏 | ❌ |

麦克风功能需安全上下文，权限被拒时自动隐藏相关面板，其余功能不受影响（规格 D-03）。

## 功能一览

| 模块 | 能力 |
|---|---|
| 节拍器 | BPM 30–300（滑杆/输入/Tap 打拍）、拍号 2/4·3/4·4/4·6/8、细分（整拍/八分/三连/十六分）、首拍重音、三种音色、渐快训练、静音小节、拍点+钟摆可视化 |
| 调音器 | 麦克风拾音、音名+音分偏差指针表、稳定度提示、定弦预设库（二胡六种弦式/二泉弦/小提琴/吉他/尤克里里/大提琴）、参考音播放、A4 校准 430–450 |
| 听音训练 | 音程听辨（旋律/和声、三档难度）、和弦性质、旋律听写填空、混合模式、组末正确率（仅会话内统计） |
| 乐谱跟练 | 简谱+音名渲染、指法常显、弓法开关、弦别染色、小节整段高亮跟随（乐谱自动居中）、可选小节内节拍竖线、换弦/换把标记就近附着谱面、顶部全局时间轴概览（点击/拖拽跳转）、变速 0.5–1.5x 不变调、A-B 循环、预备拍、节拍器叠加、移调 ±12、音准反馈（实时音分偏差） |
| 屏幕常亮 | 播放期间自动保持亮屏（Screen Wake Lock API），停止即恢复息屏；设置页可关；需 HTTPS（iOS 16.4+） |

键盘快捷键：`空格` 播放/停止 · `[` `]` 设 A/B 循环点 · 谱面上点击任意小节设为起始位置。

## 发布上线（重要：两步都要做）

> 完整发布流程、参数、踩坑清单见 **`PUBLISHING.md`**。接手发布的人（含 AI）请照那份文档走，下面是要点。

站点靠 Service Worker 提供离线能力，缓存会把资源钉住。更新后想让用户**第一次进入**就看到新版本，必须：

```bash
node tools/serve.mjs                # 起本地静态服务器（另一个终端）
node test/smoke.mjs                 # 资源可达性 + 逻辑单测
node test/dom.mjs                   # jsdom 集成测试
node tools/bump-version.mjs         # 1. 给改动过的 CSS/JS 重写 ?v=<内容hash>
                                    # 2. 然后重新部署静态站点（见 PUBLISHING.md）
```

- 脚本按文件内容算 hash：改了的文件 URL 必变（绕过一切缓存），没改的文件 URL 不变（继续吃缓存、加载更快）。
- 只想强制全网清一次缓存（极少需要）：改 `sw.js` 顶部的 `VERSION`，旧缓存桶会被整体删除。

**缓存策略**（见 `sw.js`）：

| 请求类型 | 策略 | 行为 |
|---|---|---|
| HTML / 导航 | network-first | 每次向服务器取最新 HTML；3s 超时或断网才回落缓存，离线仍可用 |
| CSS / JS | stale-while-revalidate | 命中先返回保证秒开，同时后台拉取新版；配合上面的 `?v=` 版本号保证第一次就是新的 |

早期版本对 HTML 也是 cache-first，导致「每次进去都是旧页面、必须手动刷新」，上面的组合已经修掉。

## 如何补曲目（增量只改数据）

曲库在 `js/data/scores.js`（入门曲）与 `js/data/exercises.js`（基本功），结构一致：

```js
{
  id: "unique-id",
  title: "曲目名",
  category: "basic",        // basic=入门曲目 | drill=基本功
  key: "D",                  // 调：D/G/F/C/A/bB（自动指法表按调生成）
  stringMode: "1-5",         // 弦式（仅展示用）
  bpm: 88, meter: "4/4",
  desc: "练习要点",
  text: "1[空拉] 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 - |",
}
```

### 紧凑记谱语法（js/core/jianpu.js 解析）

| 记号 | 含义 | 示例 |
|---|---|---|
| `1`–`7` / `0` | 简谱数字 / 休止 | `1 2 3` |
| `'` / `,` | 高/低八度点（可叠加） | `1'` `5,` |
| `-`（贴写） | 增时线，每条 +1 拍 | `5-` = 2 拍，`1---` = 4 拍 |
| `-`（独立写） | 同上，给前一个音加 1 拍 | `5 -` |
| `.` | 附点（×1.5 拍） | `3.` = 1.5 拍 |
| `/2` `/4` | 八分 / 十六分 | `6/2` |
| `~` | 延音线（并入前音） | `2~` |
| `[指法]` | 空/一/二/三/四；`内`/`外`开头则同时定弦别 | `5[内四]` |
| `[弓法]` | 拉 / 推 / 连（连=与前音同弓） | `1[空拉]` |
| `\|` | 小节线 | |

**自动填充规则**（省掉逐音标注，显式标记可覆盖）：
- **指法**：按调生成的一把位指法表自动填充（内弦自 D4 起四音=空一二三，外弦自 A4 起五音=空一二三四，沿该调音阶取音）。G 调外弦二指=C5、F 调内弦二指=F4 会自动正确。超出一把位的音指法留空，需显式标注（如 `2'[二把外一]`）。
- **弓法**：从第一个标记起拉/推交替；`[连]` 开启连弓组，组内音同弓，下一个显式拉/推重置交替。

## 技术要点

- **节奏精度**：前瞻调度器（25ms 轮询 + 100ms 窗口），按 `audioContext.currentTime` 排音，不用 setInterval 发声。
- **音高检测**：AnalyserNode 时域数据 + 自相关 + 抛物线插值，60–1200Hz。
- **变速不变调**：只缩放调度间隔，不改频率。
- **存储**：IndexedDB 单 store（键值）；不可用降级 localStorage；两者都不可用走内存。
- **主题**：谷歌风格（Material，默认）+ 包豪斯 / 千禧 Y2K / 赛博朋克霓虹 / 深色工业风 / 经典浅色，设置页切换。
  架构：`html[data-theme]` 两层驱动——① 每主题一组 CSS 变量（`css/themes.css`：颜色、圆角、边框宽、阴影、字体、缓动），组件自动跟随；② 各主题签名覆盖（包豪斯=方角 2px 黑边+原色硬切换+三原色条、Y2K=毛玻璃+粉渐变+光晕+弹性动效+星星装饰、赛博朋克=网格+扫描线+霓虹发光+glitch 按下、谷歌=pill 导航+圆形 logo）。
  约束：新增主题只需在 themes.css 加一个 `html[data-theme="x"]` 变量块（可选签名覆盖）并在 app.js `THEMES` 数组登记一行；未知主题值自动兜底为 google。
- **脚本加载**：全部 `defer`，保证跨浏览器执行顺序。
